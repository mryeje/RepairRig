# Production hand-pose comparison — 2026-09-11

Compared `blend/RepairRig_05_ProductionCharacter_Test.blend` with canonical `blend/RepairRig_04_ActionLibrary.blend` in isolated Blender 5.0.1 background sessions, with embedded scripts disabled. Neither scene was saved or modified on disk.

## Findings

All six hand Actions have exactly identical audited F-curve payloads. Production `POSE_Grip_Screwdriver_R` has lost its asset flag; this affects asset discovery but does not explain different curl from identical channel values.

The audited hand drivers are identical. Generated rig object matrices are identity in both files. Hand rest geometry differs in both metarig and generated rig. Inspected index/thumb settings remain Automatic, ten B-Bone segments, and no extra finger IK.

Right-hand master axes in ORG-hand.R rest space:

| Finger | Chain direction difference | Residual bend-axis difference |
| --- | ---: | ---: |
| Index | 6.09° | 136.53° |
| Middle | 16.33° | 14.27° |
| Ring | 24.57° | 102.60° |
| Pinky | 38.21° | 87.83° |
| Thumb | 33.32° | 49.39° |

The residual angle transports canonical Y onto production Y by the shortest rotation, then compares the transported X with production X. It separates changed chain aim from orientation around that direction; it is not an Euler-roll correction.

The index direction changes only slightly while its bend axis changes substantially. Ring and pinky also show large residual differences. This is strong evidence of incompatible rest/bend frames: identical master scale channels do not represent the same geometric curl on these rigs.

Evaluation-only scalar sweeps confirm different tip responses. Changing index master Y scale from 1 to 0.58 moves its tip by `(0.0052, -0.0708, -0.0053)` in canonical hand space, versus `(0.0313, -0.0665, 0.0154)` in production. Thumb displacement is `(0.0288, -0.0519, -0.0474)` versus `(-0.0089, -0.0383, -0.1010)`. Coordinates are Blender units. Different lengths and rest positions also contribute; these numbers alone do not establish anatomical correctness.

Production includes the bound `Chris-Low-poly` mesh (360,074 vertices).

## Correction path and limits

The investigation now points to production rest/bend-frame compatibility, especially index, ring and pinky, with thumb opposition requiring separate fitting. It does not yet distinguish regeneration from adjusted metarig geometry versus later generated-rig edits as the origin of the difference.

Next, use a new production-derived experiment file to compare actual mechanism axes and metarig chain curvature against the mesh before selecting targeted frame correction or regeneration. Preserve fitted joint positions. Do not copy the angles above directly into bone rolls. Thumb opposition and tool contact need production-specific pose fitting. Restoring the screwdriver asset flag is a separate small fix.

No correction was saved. Visual mesh contact, skinning, body/tool regression, and corrected-file reopen validation remain pending. Sweeps reset hand controls and detach Actions/NLA only in memory; they test scalar response, not Asset Browser application of every pose. Detailed sweeps cover the right hand only.
