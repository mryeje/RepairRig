# RepairRig — reusable Blender asset library

Start with [Asset Library Setup](Docs/Asset_Library_Setup.md), then [New Repair Project Workflow](Docs/New_Repair_Project_Workflow.md).

- **31 assets** in nine catalogs: production character, motion clips, canonical/production hand poses, two tools and a proxy worksite.
- **Blender 5.0.1 tested.** Compatible RepairRig/Rigify controls required; no automatic retargeting.
- Append complete Character/Tool Collections; run embedded `RepairRig_Library_UI.py` once after Append, then **Bind Imported Tools**.
- Prefer production hand poses for the supplied character. Keep grip/contact fitting character-specific.
- Open `Demo/RepairRig_NewProject_Validated.blend` for the independent layered example; allow trusted embedded scripts for its UI.

[Stage 6 report](Docs/Stage6_Report.md) lists files, validation, portability findings and known limitations. The original Stage 5F checkpoint was not modified.
